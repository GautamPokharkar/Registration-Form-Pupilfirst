# 📝 Registration Form Web Application

A simple **frontend registration form** built using **HTML, Tailwind CSS, and JavaScript**, demonstrating form handling, client-side validation, and browser-based data persistence using **localStorage**.

---

## ✅ Features

- User registration form with name, email, password, and date of birth  
- **Age validation** (allows users between 18 and 55 years)  
- Mandatory **terms and conditions** acceptance  
- Stores submitted data in **browser localStorage**  
- Displays submitted entries dynamically in a table  
- Responsive UI styled with **Tailwind CSS**

---

## 🧠 How It Works

- Captures user input through a registration form  
- Validates age and required fields on submission  
- Stores valid registrations in `localStorage`  
- Automatically loads and displays stored entries on page refresh  

---

## 🧰 Tech Stack

- **Languages:** HTML, JavaScript  
- **Styling:** Tailwind CSS  
- **Storage:** Browser localStorage
